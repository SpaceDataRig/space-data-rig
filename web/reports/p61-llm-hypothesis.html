P61 an LLM-chosen test, scored as a 2x2 on ground-truth classes (closed loop @ scale)

Reproduce: npm run p61:llm-hypothesis -- --pos 24 --neg 24 --deep --no-llm (models: none -> deterministic 2x2)

Both classes come from ONE token-free public source (the ExoFOP TOI table): 24 confirmed planets (positives) and 18 FP/EB dispositions (labelled blends). Each menu test is run on real photometry and scored as a full 2x2 via src/candidate/vetoAcceptance (catch-rate on blends, false-veto on known planets, acceptVetoTool). Pixel (PSF double-difference) and Gaia-dilution tests are ACTIVE (--deep).
