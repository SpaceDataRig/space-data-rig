P79 quantitative benchmark vs TCE / DAVE / TPM on our own data

Reproduce: npm run p79:benchmark (offline; reads reports/p47 and, if present, reports/p78).

We cannot run those projects' production pipelines, so we re-implement each one's headline statistic (src/detect/benchmark.ts, 8 offline tests) and apply it to numbers our own pipeline measured on real TESS-SPOC photometry. The TPM coefficients are FIT TO OUR GRID (not Burke's Kepler numbers).

TCE rule vs our measured recovery: cells the TCE SNR>=7 + 3-transit rule would ACCEPT average 74% measured completeness (24 cells); cells it would REJECT average 0% (6 cells). That separation is the quantitative check that our detector's completeness tracks the standard BLS/TCE detection limit on the same real data.

Published external reference (DIFFERENT instruments -- orientation, not equivalence)

  • Kepler TPS: ~90% completeness for Neptune-size planets at <4d, falling for longer periods / smaller radii (Burke et al. 2015). Different instrument + much longer baseline.
  • TESS TCE pipeline is BLS-based like Kepler's but tuned for 2-min SPOC; published TCE completeness is mission-level (thousands of targets, multi-sector).
  • TRICERATOPS (DAVE successor) validates TOIs to FPP < 1e-3 using space-to-ground + contrast limits; our daveBlendedFpp is a first-order analogue.

Honest scope: this is a reproducible comparison harness built from our own measurements, not a run of TCE/DAVE/TPM themselves, and the completeness is on bright catalogued hosts (efficiency, not a survey selection function). Measure only; nothing gated, anchored, claimed, or deployed. discoveryClaim false, safeToGate false.
