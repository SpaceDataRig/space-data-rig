Reproduce: npm run p99:heldout-blind (offline, deterministic; every input is a committed byte-exact sealed-truth fixture). This upgrades the rig's RETROSPECTIVE operating point to a PROSPECTIVE blind split, the held-out truth is sealed and never touches tuning. A validation-METHODOLOGY measurement, NOT a new gate and NOT a discovery. discoveryClaim:false, safeToGate:false.

4. Independent corroboration of survivors

Survivors (held-out curves accepted OR needs-more-data at the frozen point): 66; of these 0.55 fraction are truly injected (the honest held-out precision of the SURVIVOR class). Two INDEPENDENT committed channels:

  • literature cross-match (ExoFOP-validated external.jsonl): 10 survivors match a confirmed host (10 validated).

5. Retrospective -> prospective deviation

Held-out recall differs from the tuning set by 6.8 percentage points and precision by -2.2pp. A small deviation says the tuned operating point generalizes; a large one exposes retrospective optimism (the metric the earlier single-sample reports could not, because they tuned and scored on the same curves).

Reading (honest)

This is a prospective test of the METHOD on a committed sealed-truth fixture, so the answer key is real but the injected planets are synthetic transits on real host curves (the sanctioned P49/P82 protocol) -- it calibrates tuning-vs-generalization bias and the corroboration yield, it does not validate against a live unconfirmed candidate list. The corroboration channels only cover hosts already in the confirmed/Gaia fixtures, so a low survivor count caps the corroboration-rate precision; all ceilings are stated.
